# Como usar o template:
1 . Clone este repositório:
```bash
git clone https://github.com/NevermoreRaven12/myts-template 
```
2 . Instale as dependências: 
```bash
npm install
```
3 . Configure o banco de dados no arquivo `datasource.ts`

4 . Crie suas entidades dentro da pasta `entity`

5 . Compile o código: 
```bash
tsc
```
6 . Para rodar o código: 
```bash
node build/seuArquivo.js
```
